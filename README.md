# Nebelmeer

Einzelspieler-Prototyp (Alpha): Du fährst mit Boot und Laterne durch den Nebel, findest Inseln, Siegel und Geheimnisse. Manches zeigt sich nur bei Nacht, manches nur dem, der stehen bleibt.

Das ganze Spiel ist eine einzige Datei (`index.html`), ohne Server und ohne Build. Der Spielstand liegt im Browser (`localStorage`). Einzige externe Ressource sind die Schriften von Google Fonts.

Gehört zum [Leif Game Hub](https://lgh.leifps.workers.dev). Die Mehrspieler-Fortsetzung ist [Nebelmeer: Tiefe](https://github.com/LeifPS/nebelmeertiefe).

Steuerung: WASD oder Pfeiltasten, am Handy auf dem Bildschirm ziehen. E untersucht, M öffnet die Karte, J das Journal.
